# 說明提示仍寫給核可的人看

## 現象
說明命令列的系統提示(`src/rtb/analyzer/narrate.py` 的 `SYSTEM_PROMPT`)開頭寫「你替人工核可預算調整的人寫一段提案風險說明」。實際上人工核可表單組表單時不帶說明(見 [[Systems/展示頁面]] 2026-09-28 一節),一鍵展示也要等情境整段跑完才產說明,核可的人在核可當下看不到它;說明只出現在展示頁「其餘明細」的說明卡。頁面、流程圖、驅動與說明模組的註解都已改成「只給人看」,提示是唯一還這樣寫的地方。

## 為什麼這次不改
提示逐字算進說明的錄製鍵。改一個字,入庫的 `recordings/model/phase14-demo` 說明錄製就全部找不到,展示重播會退成「AI 這次沒有給出回答」,要協調者用真模型重錄。只為了改讀者稱呼去重錄不划算。

## 要做的(事件觸發)
- 觸發事件:下一次因為任何原因要重錄展示說明錄製時——系統提示、證據白名單、政策版本或錄製鍵格式改動都會讓錄製鍵失效。入口:重播守衛 `test_committed_demo_recordings_replay_f1_to_f6_with_narratives` 翻紅,或協調者跑 `python -m rtb.demo.recordings` 做入庫前檢查時。
- 那時把提示的讀者改成「看展示頁的人」(不要寫成核可者),跟著重錄、重跑入庫前檢查,並把本篇標 resolved。
- 不要單獨為這件事重錄。
