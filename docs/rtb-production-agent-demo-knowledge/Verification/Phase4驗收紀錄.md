## 偏離與缺口

- F3 分析費用只保證「同一個任務被同時推進時,同一時間只有一個持有有效租約的一方花錢」;持有者寫入前當機、或一步做超過租約被接手時會再分析一次。交接文件原文是「不會重複分析費用」,這是至少一次的代價,合約措辭照實寫(使用者裁定)。
- 新舊版本不能混跑是部署規則,不是機械圍籬:舊版的程式已寫死、看不到新版。
- 租約 60 秒、忙碌連續 3 次、DSP 逾時小於租約 1/6 都沒有實測校準,各掛了回頭條件(2026-12-31)。
