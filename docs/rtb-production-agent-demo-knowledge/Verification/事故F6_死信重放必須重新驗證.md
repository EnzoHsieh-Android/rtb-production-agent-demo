# 事故F6_死信重放必須重新驗證

預告的合約:事故 F6:死信佇列裡的舊工作(還沒開始嘗試、投遞次數用完的提案)只能由管理指令逐筆重放,不會自己再交出去;重放只把它放回待處理,之後照一般流程重跑每一關(廣告現況與版本、政策版本、決策新鮮度、權限、比例與總曝險、核可),沒有略過任何一關的旗標。廣告版本變了、提案的政策版本不是現行版本、或決策建立超過 15 分鐘(證據新鮮度以決策建立時間代理;有這一次真的需要、此刻有效的核可則不判)就擋下並給對應原因,分析端另開接續任務重新規劃,舊決策不會寫進 DSP;都沒變就照常寫成。已不是死信(已放回、已擋下)、已過期、同任務已有更新的修訂、或存的內容讀不回的,拒絕重放。收件口回死信而決策還沒過期時分析端等待,已過期就結案、不重新規劃。每一次進死信、要求重放與其結果,都寫進只增不改、不被清理的死信信封與稽核。
