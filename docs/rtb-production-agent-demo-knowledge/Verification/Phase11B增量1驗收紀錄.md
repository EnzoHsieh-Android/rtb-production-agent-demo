## 這次上了什麼

- **模型用戶端**:只有它能碰模型(全庫掃描守 [S917]);拆成共用詞彙、Claude Code 後端、錄製、帳本、協調五支模組。(2026-10-02 更正:「五支」是五種角色;按檔案算當時就有 8 支——帳本另拆出 modelledger_view、modelledger_writeoff,加上即時實測命令列 modelverify,現在仍是這 8 支 `src/rtb/model*.py`,見 [[Systems/模型用戶端]]。)
- **模式**:預設重播錄製,不會花錢;即時模式要有綁 claude 版本的本機實測紀錄才開,版本不同、背景執行緒、設定錯誤都結算 0 並停下。
- **花費**:每次呼叫先預留、事後結算,每次展示 1 美元、每月 20 美元的上限在交易裡判定(使用者本人裁定的數字,沒動)。預留照「1 次請求加最多 3 次自動續寫」算,約是單次的 4 倍。
- **行程安全**:claude 在自己的行程群組跑;逾時、Ctrl-C、SIGTERM、SIGHUP、SIGQUIT 都殺整組並清錄製佔位;忽略 SIGHUP 的 nohup 執行照舊忽略。
- **評估**:值不值得加的模型候選,相同提示只呼叫一次;重播逐列核對結果、原價、延遲與共用標記,竄改或缺列就掛旗標、不判門檻。
- **測試不碰真帳**:整套測試把帳號家目錄換成暫存目錄,子行程也一樣;開始與結束比對真帳沒變。
