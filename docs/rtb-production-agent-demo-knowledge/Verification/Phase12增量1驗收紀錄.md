## 這次上了什麼

- **分析端正式驅動命令列**:每輪推進未結束的任務;SIGTERM/SIGINT 後一步內停;逾時設定不安全(非有限、≤0.1 秒、或 2×逾時×2 ≥ 租約)拒絕啟動(S1001)。(2026-10-03 更正:是小於 0.1 秒才拒絕,剛好 0.1 秒放行;推送當時的 eade8e7 也是這樣,見 `src/rtb/analyzer/runner.py` 的 `MIN_TIMEOUT_SECONDS` 與 `t >= MIN_TIMEOUT_SECONDS` 那個判斷。)
- **啟動器與金鑰**:子行程環境只給白名單(S1003);三把金鑰每次展示不同、只發給該拿的角色(S1004 前半、S1059);停止會收掉整個行程群組,含孫行程與領頭先死的情況。
- **故障交付**:設定檔只存隨機值雜湊,六項核對(根目錄、標記檔、隨機值、角色、目標路徑用正式入口 parser 解析、猝死點)不過一律代碼 3,不退回正常啟動;同一份交付只能用一次(S1049)。
- **展示驅動程式**:F1–F7 各起真的 DSP、收件口、執行迴圈、分析端;觀察器只經各系統的唯讀出口讀紀錄;每個情境逐工作、逐紀錄照順序核對必經步驟與允許的回頭,多出來的一律判沒跑完;平台真實狀態經 DSP 唯讀端點讀(S1006–S1012、S1047、S1057、S1058、S1064)。
- **全部跑一次**:F1–F7 依序跑,每個情境結束行程全收(S1005),最後跑宣稱驗證器並原樣記下輸出。
- **共用 HTTP 基礎**:新增回應物件(HTML/CSS/303,轉址只收本站路徑)與讀表單(同源、嚴格 UTF-8、重複欄位拒收);宣告內容安全政策的伺服器每個回應都帶政策標頭;既有 JSON 伺服器的回應逐位元組不變(S1051)。共用用戶端一律直連、不走環境變數裡的代理。
