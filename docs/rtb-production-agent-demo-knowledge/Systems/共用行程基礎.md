# 共用行程基礎

`src/rtb/httpkit.py`(httpkit)提供伺服器與處理程式基底:子類別實作 handle_request,需要時覆寫 map_exception 把自己的例外對應成錯誤回應。`src/rtb/sqlitekit.py`(sqlitekit)提供連線與寫入交易。使用者見 [[Systems/Mock-DSP]];之後的提案收件口也用這兩個模組。

已知缺口(如實標明):
- 逾時是「每次接收的閒置逾時」,不是整個請求的期限:慢速滴入(每個逾時內送一點)可以佔住一條執行緒直到本文上限。DSP 抽出前就是這樣,沒有變糟,但之後的提案收件口會繼承。
REVISIT:2026-10-20 提案收件口實作完成後,評估是否加上整個請求的期限。
- `read_json` 只能讀一次(讀第二次是程式錯誤,會回 500);`NoResponse` 是通用的「刻意不回應」機制,目前只有 DSP 的故障注入在用。
- 共用行為的測試分兩處:tests/kit 測共用基礎本身,tests/dsp 測 DSP 的路由與業務;兩邊對同一種行為(例如逾時)都有覆蓋屬於有意的重疊,改共用行為時兩邊都要跑。
