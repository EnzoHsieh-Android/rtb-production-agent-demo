# 死信重放指令

本篇管 `src/rtb/executor/replay.py`:Phase 8 的死信重放管理工具。設計、合約與三輪設計審見 [[Projects/RTB_Phase8死信重放與過時決策_計劃]];重放條件、放回待處理、死信信封與稽核在 [[Systems/提案收件口]];放回之後的每一關在 [[Systems/執行迴圈]]。

- 比照核可管理工具的命令列形狀(收資料庫路徑與參數、出錯以非零代碼結束、資料庫忙碌回同一個代碼),核可工具見 [[Systems/寫入能力憑證]]。
- 一次一份:不做自動、排程或批次重放,也不做網頁介面(計劃〈不做〉)。
- 操作人不合識別格式就拒絕、不寫稽核(沒有可信的操作人可記)。防回歸:[test:test_a_replay_without_a_valid_operator_is_refused_without_an_audit_row]、[test:test_the_replay_tool_requeues_a_dead_letter_and_reports_refusals]。
- 時鐘交給收件口的重放方法、在拿到寫入鎖之後才讀,不在工具這一層先讀(等鎖期間提案可能過期;2026-09-24 代碼審第 1 輪外家席)。防回歸:[test:test_a_replay_reads_the_clock_after_taking_the_write_lock]。
