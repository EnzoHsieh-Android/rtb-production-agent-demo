# 靜態檢查閘

`tools/mypy_sarif.py` 執行 `python -m mypy`,解析文字輸出,寫出 SARIF 2.1.0;結束碼 0 表示轉換成功(有型別錯誤也是 0,由 lumos 判斷告警),2 表示 mypy 本身無法產出可用結果。CI 設定在 `.github/workflows/ci.yml`(不是程式檔,不需要家),每次 push 都會跑 ruff、mypy 與 pytest(不開 pull request 觸發)。
