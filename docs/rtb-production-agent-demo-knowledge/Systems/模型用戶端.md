# 模型用戶端

模型呼叫的共用部分。2026-09-24 使用者改裁定模型後端改用本機 Claude Code 非互動模式(計劃改第 5 版),
增量 1 先正式落地跟後端無關、而且不依賴模型用戶端本身的兩件事;其餘寫好的部分放在分支上標明半成品的本機提交,
等第 5 版計劃定了後端介面再拆。

## 已落地

- `src/rtb/modelledger_view.py`:花費帳的唯讀開法。帳本三張表(預留、結算、核銷)都只增不改;這裡只有讀法、
  欄位清單,以及「一筆呼叫算進已用多少」的規則(沒結算照預留、結算了照含係數金額、有核銷照核銷金額、核銷後
  才來的結算取較高者),寫入端檢查上限時用同一份。呼叫者、來源、結果類別三個封閉列舉也放這裡,維運的指標讀
  它們當有界標籤、不必載入任何送出呼叫的程式。帳檔位置固定在家目錄 `~/.rtb/model-ledger.sqlite`。
  指標怎麼讀見 [[Systems/有界標籤的指標]]。
- `tests/conftest.py`:整套測試共用的隔離夾具(每支測試一個暫存家目錄、清掉模型金鑰與模式開關;整套開始記下
  真帳狀態、結束再比,變了就讓整套失敗)。
- `tests/test_suite_isolation.py`:[S932] 的測試。

## 半成品(分支上的本機提交,等第 5 版計劃)

模型用戶端本體(預留、結算、核銷、錄製讀寫、佔位符)、核銷命令列、金鑰只給模型行程、接入點 3 的模型候選與
比較表,以及它們的測試。跟 Anthropic API 綁死的部分(共用 HTTP 用戶端加的兩個標頭、x-api-key、刪金鑰、
[S905]、[S906] 的測試)在第 5 版會改;其餘(花費帳、錄製、評估候選)跟後端無關,但目前經 HTTP 送出的程式
與測試纏在一起,要等後端介面定了才拆得乾淨。
