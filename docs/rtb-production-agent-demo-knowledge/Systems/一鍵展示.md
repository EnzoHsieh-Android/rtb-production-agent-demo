## 啟動與故障交付

- `src/rtb/demo/keys.py`:每次展示的三把金鑰(能力、稽核、核可),文字形式;`repr` 不印金鑰。
- `src/rtb/demo/launcher/__init__.py`:子行程啟動(`start`,獨立行程群組,`stop` 連孫行程一起結束)、環境白名單(`child_env`)、展示根目錄(`prepare_root`,寫標記檔)、把故障請求交給故障套件寫成設定檔(`write_fault_plan`)。沒排故障的子行程直接跑正式入口(`python -m` 正式模組)。

- `src/rtb/demo/state_store.py`:展示狀態暫存資料庫。驅動程式寫(每次寫入一條短連線),伺服器用唯讀開法讀;記情境起訖與結果、每筆判斷(帶來源)、目前節點、F7 的各節點筆數。
