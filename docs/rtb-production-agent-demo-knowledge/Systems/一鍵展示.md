# 一鍵展示

Phase 12 的展示套件。計劃:[[Projects/RTB_Phase12一鍵展示與HTML報告_計劃]]。

## 流程圖怎麼對到系統

- `src/rtb/demo/flow.py` 是流程圖本身:48 個節點(24 個一般步驟、17 個判斷點、7 個結束點,其中 10 個是回頭節點)、68 條分支,五條泳道;另外放系統結果對應表、判斷點綁定表、回頭轉換清單與禁用術語掃描。`src/rtb/demo/state.py` 是頁面與伺服器共用的資料結構(Codex 那份的原樣複本);`src/rtb/demo/__init__.py` 只是套件宣告。

- 節點的內部編號用 a_(分析)、i_(收件)、x_(執行)、p_(廣告平台)、h_(人工)開頭;顯示給人看的是標籤。
- 對到的列舉來自這幾處的家:[[Systems/提案收件口]](處置、擋下原因、死信原因、停下種類、生命週期事件、重放結果)、[[Systems/執行迴圈]](作廢結果、執行迴圈結果)、[[Systems/任務流程領域模型]](任務狀態、嘗試狀態、結果代碼)、[[Systems/分析行程流程與檢查點]](重新規劃原因、分析端路由、不提案原因)。
- 一個成員可以對到節點或邊,好幾個成員可以對到同一條邊(例如六種執行前檢查沒過都在「寫入前再確認 → 擋下」這條邊上),白話說明各自不同;判斷紀錄表顯示的是成員自己的白話,圖上顯示的是邊的標籤。
- 驅動程式(增量 1 之後的部分)記判斷時,用這份對應表把系統實際的結果換成圖上的邊與白話原因。
