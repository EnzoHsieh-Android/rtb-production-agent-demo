## Finding 2:大整數與浮點混合時,合法資料被判成 INVALID_DATA;極小值下溢成 0.0 或分母為零

severity: minor

## Finding 4:路徑解析改用 urlsplit 後,`//` 開頭的路徑會被當成有 authority 而剝掉前段,原本 404 的請求現在會被路由

severity: minor
blocking: 否,Mock DSP 只綁回送位址,無認證,行為差異只讓少數畸形請求從 404 變成 200,沒有資料越權。

- 位置:`src/rtb/dsp/server.py` `_route`
- 引句:「match = pattern.match(urlsplit(self.path).path)」
- 實測對照(舊 = `path.split("?")[0]`,新 = urlsplit):

| 輸入 | 舊 | 新 |
|---|---|---|
| `/campaigns/c1/metrics?window=1d` | 命中 c1 | 相同 |
| `/campaigns/c1?` 與 `/campaigns/c1?x#y` | 命中 c1 | 相同 |
| `/campaigns/c1#x` | 命中 id 為 `c1#x`(查無廣告 404) | 命中 c1(較好,fragment 本不該送到伺服器) |
| `/campaigns/c1/metrics#frag?window=1d` | 不匹配 404 | 命中 c1/metrics(較好) |
| `http://h/campaigns/c1`(絕對形式) | 404 | 命中 c1(較好,HTTP 允許) |
| `//evil.com/campaigns/c1` | 404 | 命中 c1(authority 被剝掉,較怪) |
| `///campaigns/c1` | 404 | 命中 c1(較怪) |
| `//campaigns/c1` | 404 | 404(被解讀成 host=campaigns,path=/c1) |
| `/campaigns/c%31`、`/campaigns/c1%2Fmetrics` | 不解碼,id 含百分號 | 相同,兩者都不解碼,無回歸 |
| `/campaigns/c1\n` | 命中 id 含換行 | 命中 c1(urlsplit 會刪 tab 與換行;實際請求列不可能帶) |

- 結論:百分比編碼行為一致(仍不解碼);`?`、`#` 較舊版更好;唯一的怪處是 `//host/...` 形式現在會路由。`_get_metrics` 用同一個 `urlsplit(self.path)`,路由與查詢字串來源一致,無不一致風險。
- 建議:要嚴格就在 `_route` 前擋 `self.path.startswith("//")` 回 404,並補一個測試;不做也可,但知識筆記應提一句。
