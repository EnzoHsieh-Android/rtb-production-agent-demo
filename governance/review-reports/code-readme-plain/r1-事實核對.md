## 3. 驗證器對故障注入測試的檢查寫得比實際強

severity: minor
blocking: 否
引句:「有故障注入時，還會確認測試真的用了指定故障方式並驗證結果」
查證 file: `tools/verify_claims.py:1116`、`tools/verify_claims.py:1137`、`tools/verify_claims.py:1140`

驗證器自己的說明是「只證明有注入、有斷言，不證明注入有意義（天花板，歸審查員）」（verify_claims.py:1116）。實際只做兩件事：

- 用語法樹確認測試或它用的 fixture「提到」宣告的注入手段名稱（`_mentions`）。
- 確認測試本體有 assert、`pytest.raises` 或 `assert_*` 呼叫（`_asserts`）。

它不確認故障真的發生，也不判斷斷言驗的是不是結果。「真的用了」和「驗證結果」會讓讀者以為是語意層的保證。舊稿寫的是「測試真的用了宣告的注入手段、而且有斷言」，比較接近實情。

建議改法：改成「有故障注入的宣稱，還會檢查測試有引用宣告的故障手段、而且有斷言（只是機械檢查，不判斷注入有沒有意義）」。
