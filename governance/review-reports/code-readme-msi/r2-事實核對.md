### 1. 「成本這次沒量」與報告不符:模型成本有量,只是沒設門檻、也沒跟程式比

severity: minor
blocking: 否
引句:「這是一般性理由，成本這次沒量」

查證 file:
- `governance/eval/phase13-investigation-adoption.md:119`:每次成本(美元,單次呼叫最高原價)0.006982,有量。
- `governance/eval/phase13-investigation-adoption.md:120`:「每次成本:不設門檻(假設正式環境用自研模型、成本另計)」。
- `governance/eval/phase15-rule-mining.md:25-29`:三批各自記了估算花費(約 0.026 美元)。
- `docs/rtb-production-agent-demo-knowledge/Projects/RTB_Agent_Phase0架構.md:89`(d13 why_chosen):「成本沒量」,問題相同。

問題:兩份報告都量了模型花費。沒做的是成本門檻(使用者裁定不設),以及跟程式成本的對照。寫成「沒量」,讀者去對報告時會發現對不上。這句說法偏保守,沒有誇大,所以不是 blocking。

建議改法:README 第 5 行改成「……這是一般性理由;成本這次不設門檻、也沒跟程式比」。d13 的 why_chosen 同步改成「成本不設門檻、沒跟程式比」。第 68 行「撤除條件……沒量成本與風險」的意思是撤除條件沒納入成本與風險,可以保留,或改成「沒納入成本與風險」,避免同一個詞有兩種意思。
