## 發現 1：「資料自相矛盾整份不收」放在 investigation，其他跨欄一致性檢查都在 dsp_client

**影響**：
- 現在由兩處決定「這份原始回應不收」。
- 行為上等價：
  - instrumented 只在收據不是 none 時才存 raw，所以矛盾資料不會寫進 investigation_raw。
  - tool_calls 兩邊都照 HTTP 結果記 ok。
- 要注意的是讀取端：往後若有程式拿 `QueryRead.raw` 當「已驗過的原始回應」，就會拿到矛盾資料。

**例子**：
