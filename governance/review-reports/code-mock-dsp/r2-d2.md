## Finding 1:body 讀取逾時被當成內部錯誤,每個停滯請求印一份完整 traceback

檔案位置:`src/rtb/dsp/server.py:160`(`_read_json` 的 `rfile.read`)與 `src/rtb/dsp/server.py:110` 的 `except Exception`。

severity: minor
blocking: 否 只影響本機日誌噪音與錯誤分類,不改資料也不越權。

問題:`_read_json` 只捕 `ValueError`,`SOCKET_TIMEOUT_SECONDS` 到期丟出的 `TimeoutError` 落到通用 `except Exception`,被當成「沒預期的內部錯誤」。攻擊者(或壞客戶端)宣告 `Content-Length: 100` 只送 1 個位元組,就讓伺服器 10 秒後往標準錯誤印一份約 12 行 traceback 並回 500 internal_error;大量重複即灌爆日誌。該例外正是 `handle_error` 刻意靜音的那一類,兩處分類自相矛盾。

引句:「traceback.print_exc(file=sys.stderr)」

重現(輸出實測):對 DSP 送 `POST /campaigns/c1/pause`、正確 Host、`Idempotency-Key: st`、`Content-Length: 100`、只送 `{` 後不再送。結果:耗時 10.01 秒,回 `HTTP/1.0 500`、`{"error": "internal_error", "retryable": false}`,err.log 出現 `TimeoutError: timed out` 的完整 traceback。

## Finding 2:Host 精確比對誤擋合法本機客戶端

檔案位置:`src/rtb/dsp/server.py:139`(`_check_host`)。

severity: minor
blocking: 否 只造成少數合法寫法被拒,回應為明確 400,沒有安全缺口。

問題:比對是區分大小寫的整串相等。RFC 規定 Host 主機名不分大小寫,所以 `Host: LOCALHOST:PORT` 被擋;沒有 Host 的 HTTP/1.0 請求(舊式探針、部分健康檢查工具)也被擋。實測結果:`LOCALHOST:PORT`、缺 Host 的 HTTP/1.0 請求均回 400 `invalid_host`。這是安全側的誤擋,不是繞過;若接受此取捨,應在筆記寫明(目前筆記只說「防 DNS rebinding」)。

引句:「if self.headers.get("Host") not in (f"127.0.0.1:{port}", f"localhost:{port}"):」

重現:`printf 'GET /campaigns/c1 HTTP/1.0\r\n\r\n'` 以 socket 送到 DSP 埠,回 `400 invalid_host`;同樣請求改帶 `Host: LOCALHOST:PORT` 亦回 400。

## Finding 3:冪等鍵正則的 `$` 放行結尾換行(儲存層可達,HTTP 層不可達)

檔案位置:`src/rtb/dsp/store.py:360`(`IDEMPOTENCY_KEY_PATTERN`)與 `_validate`。

severity: minor
blocking: 否 HTTP 層實測無法送出結尾換行的鍵,只有直接呼叫儲存層才會中。

問題:`re.match` 加 `$` 會在字串尾端換行前也成立。實測 `CampaignStore.execute(Operation("c1","update_budget",{"new_budget":5},1,"abc\n"))` 被接受並寫入,歷史裡留下 `idempotency_key='abc\n'`,與 `abc` 被視為兩把不同的鍵。經 HTTP 送 obs-fold 續行(`Idempotency-Key: kf\r\n \r\n`)得到 422,因 http.client 解析後值含 `\r\n ` 而非單一結尾 `\n`,所以目前不可利用;但這個檢查在儲存層本應獨立成立,`test_idempotency_key_must_be_short_plain_ascii` 也沒有涵蓋 `"abc\n"`。修法:改用 `fullmatch` 或 `\Z`。

引句:「IDEMPOTENCY_KEY_PATTERN = re.compile(r"^[A-Za-z0-9._:-]{1,128}$")」

重現:`CampaignStore(db).execute(Operation("c1","update_budget",{"new_budget":5},1,"abc\n"))` 回傳成功,`history("c1")[0].idempotency_key == 'abc\n'`。
