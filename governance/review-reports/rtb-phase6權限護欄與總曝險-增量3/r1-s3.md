### 2. 「待核可」沒有接進收件表既有的 PENDING/IN_PROGRESS/OPEN 判準,保留期清除與取件都繞不到它

severity: major

```
OPEN = f"(({PENDING}) OR ({IN_PROGRESS}))"
```
`_purge_finished_tasks` 用 `HAVING SUM({OPEN}) = 0 AND MAX(received_at) < now - RETENTION` 判斷要不要整個任務砍掉;`receive()` 取件的 SQL 是 `WHERE ({PENDING}) OR ({IN_PROGRESS} AND lease_until <= ?)`。待核可的處置值(`disposition = 'awaiting_approval'`)不屬於 PENDING(disposition 非空)也不屬於 IN_PROGRESS(值不是 `in_progress`),所以這兩處既有查詢都會把它當成「已結束、跟我無關」的列:
