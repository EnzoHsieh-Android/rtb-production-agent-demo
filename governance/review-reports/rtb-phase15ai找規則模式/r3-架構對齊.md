## 發現 1:窮舉排序改用 Wilson 95% 下界,與既有 `rtb.eval.scoring.wilson_lower` 是同一計算的第二種實作

delta 為回應 r2 發現 `l1_4`,在窮舉排序鍵新增 Wilson 95% 下界,並自訂公式、自訂精度與捨入方式,而不是呼叫
同一套件裡已有的 `wilson_lower()`。`src/rtb/eval/scoring.py:38-46` 已有正式的 Wilson 下界實作,供 Phase 10
正式報告的信賴下界使用:

```
Z_95 = 1.959963984540054
def wilson_lower(successes: int, n: int, z: float = Z_95) -> float:
    p = successes / n
    denominator = 1 + z * z / n
    center = p + z * z / (2 * n)
    margin = z * math.sqrt(p * (1 - p) / n + z * z / (4 * n * n))
    return (center - margin) / denominator
```

這是同一條數學公式(`(center-margin)/denominator`),但既有實作用純 `float` + `math.sqrt`、精確的
`Z_95 = 1.959963984540054` 常數;delta 新寫的是用 `Decimal` 精度 50、`ROUND_HALF_EVEN`、寫死較粗的
`z=1.96`。兩支互不呼叫、互不共用常數,是同一個統計量在同一個 `rtb.eval` 套件裡的兩套獨立實作,屬「第二種
做法」。
