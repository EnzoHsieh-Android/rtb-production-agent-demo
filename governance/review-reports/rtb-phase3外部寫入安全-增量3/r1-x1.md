`begin()` 建立第一列時把 `send_count` 設為 1；現有 API 只有「結果不明 → 嘗試中」會增加它。DSP 又是在讀本文及寫入之前驗證憑證，因此收到 `capability_expired` 時仍處於「嘗試中」。設計隨即從這個狀態再次送出，卻明定不寫新列；既沒有合法的自轉換，也沒有專用操作能把次數增加到 2。
