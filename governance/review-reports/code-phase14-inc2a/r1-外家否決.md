## 發現 1: 合法的逐日金額會讓七日物化整批回滾

## 發現 2: 歷史摘要與回傳列不是同一個快照
severity: major
blocking: 是

引句:「counts = self._conn.execute(」

`history_limited` 先查摘要，再以另一個無交易保護的查詢取最近 50 列。若預算寫入落在兩次查詢之間，回應會含新的加額列，摘要卻說最近加額為零；`check_history` 仍接受，AI 收據也顯示零。這違反 [S1422] 要求完整操作集合的近期旗標與計數能可靠反映歷史。file: `src/rtb/dsp/store.py:721`

最小重現是在第二次 SELECT 前插入正常預算操作；以包裝連線固定該交錯：

```python
from pathlib import Path
from datetime import datetime, UTC
from dataclasses import asdict
from rtb.dsp.store import CampaignStore, Operation
from rtb.analyzer.dsp_client import check_history
from rtb.analyzer.investigation import QueryOption, receipt_payload

now = datetime(2026, 9, 26, tzinfo=UTC)
s = CampaignStore(Path(":memory:"), clock=lambda: now.isoformat())
s.seed_campaign("c1", 100)

class Race:
    def __init__(self, conn):
        self.conn, self.done = conn, False
    def __getattr__(self, name):
        return getattr(self.conn, name)
    def execute(self, sql, params=()):
        if "ORDER BY operation_id DESC LIMIT" in sql and not self.done:
            self.done = True
            s.execute(Operation("c1", "update_budget",
                                {"new_budget": 120}, 1, "raise"))
        return self.conn.execute(sql, params)

s._conn = Race(s._conn)
rows, summary = s.history_limited("c1")
body = {"history": [asdict(row) for row in rows], "summary": summary}
print([(row.action, row.operation_id) for row in rows])
print(summary["budget_changes_last_3d"], summary["has_recent_budget_change"])
print(check_history(body) is not None)
print(receipt_payload(QueryOption.CHECK_CHANGE_HISTORY, body, now))
s.close()
```

輸出包含 `('update_budget', 1)`，但摘要是 `0 False`；`check_history` 回 `True`，收據的 `budget_changes_last_3d` 是 `"0"`。
