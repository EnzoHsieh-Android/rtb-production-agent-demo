**1. 上一輪「單一情境重跑」的結果在新展示跑的時候還蓋在頁面上，「現在進度」會指到已經結束的舊展示**

**2. 伺服器被 Ctrl-C 或 kill 關掉時，驅動起的子行程全部變成孤兒繼續跑**
severity: major
blocking: 是
引句：「self.thread = threading.Thread(target=self._drive, args=(run, writer), daemon=True)」

  - 補一條「伺服器收到 SIGINT/SIGTERM 後沒有殘留子行程」的測試。

**查過沒問題的部分**(實際起伺服器，HOME 導到 `/tmp/p12i2-srv/_home`,用 curl 打)
- **路由與錯誤頁**:
  - 每個回應(含 404、409、400 錯誤主機、501)都帶完整的安全政策標頭，裡面有 `frame-ancestors 'none'` 與 `form-action 'self'`。
  - HEAD、OPTIONS、PUT、DELETE 都回 501 的 HTML 錯誤頁，未知路徑回 404,GET /run 回 404。
  - `?scenario=<script>` 不會出現在頁面上。
- **POST 防護**:
  - 以下各種情況都被拒:
    - 沒帶 Origin 也沒帶 Sec-Fetch-Site、cross-site、same-site、`Origin: null`、外站 Origin、Origin 用 localhost 但主機是 127.0.0.1:都回 403。
    - 錯的隨機值、非 ASCII 的隨機值、隨機值放在查詢字串:都回 403。
    - 重複欄位回 400,未知情境代碼 F9 回 400。
    - text/plain 與 multipart 回 415。
  - 隨機值只出現在主頁與確認頁的表單裡，不在報告、轉址網址或子行程環境變數中。
- **同時只跑一次**:同時送 3 個 POST /run 都回 303,只產生 1 個展示目錄。
- **確認頁**:
  - 少勾一格、展示編號不對、數字摘要不對、勾選值不是 1、跨站送出正確表單:都被拒(403)。
  - 同一份表單在核可已寫進平台後重送，回 409。
  - 用瀏覽器實際勾選送出，簽到的是頁面顯示的 k0144/t0144。F7 判 done,結論是「確認的那一筆帶著這次展示簽發的核可寫進平台」。
- **縮小版全部跑一次**:七個情境都 done,驗證器通過，另存 `demo-full-…html`;F7 重跑另存 `demo-rerun-…html`。
