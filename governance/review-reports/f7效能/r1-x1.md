### F1 資料庫空集合的加總結果未定義，第一筆預留可能直接報錯
severity: major
blocking: 是
引句:「已用額度改成資料庫端加總,舊算法留作對照,兩者在同一份資料上必須給一模一樣的答案。」
舊算法用 Python `sum(...)`，沒有任何持有額度時回傳 `0`；SQLite 的裸 `SUM(...)` 在零列時回傳 `NULL`。設計與 [S680] 列出的資料類別都沒有要求空資料、新租戶或各子查詢零列的案例，也沒有指定 `COALESCE`。現有判門檻會直接拿結果與本次金額相加。file: `src/rtb/executor/attempt_store.py:602`；file: `src/rtb/executor/attempt_store.py:569`

具體例：空的 `attempts` 表，租戶 `t` 第一筆預留 50、門檻 50 → 預期已用額度為 0，剛好達門檻而放行 → 照裸 SQL `SUM` 實作得到 `None`，執行 `None + 50` 時報錯，第一筆永遠無法開始。

建議改法：明定每段聚合都以 `COALESCE(SUM(...), 0)` 回傳整數；[S680] 額外綁定空資料、查詢租戶沒有任何列、只有已驗證列、只有未結案列等零列組合，不能只依賴隨機資料碰巧產生。

### F2 SQLite 動態型別會讓新舊算法對毀損金額得出不同結果
severity: major
blocking: 是
引句:「有租戶的列(Phase 6 之後寫的):讓資料庫直接加總預留金額,不把列取回程式」
SQLite 的 `INTEGER` 欄位不保證實際儲存型別；現有逐列算法對 `reserved_amount` 呼叫 Python `int()`，裸 SQL `SUM` 則使用 SQLite 的數值轉型規則。兩者對文字、浮點數及 BLOB 不等價，而 [S680] 只列正常業務狀態，[S682] 只涵蓋舊列快照毀損，沒有涵蓋有租戶新列的金額型別毀損。file: `src/rtb/executor/attempt_store.py:697`；file: `src/rtb/executor/execution.py:777`

具體例：一筆窗內已驗證列的 `tenant='t'`、`reserved_amount='x1'`，再嘗試預留 50、門檻 50 → 預期不得把毀損列當成零後放行；舊算法的 `int('x1')` 失敗，不會送出外部寫入 → SQLite `SUM('x1')` 得到 `0.0`，新算法會判定 `0 + 50` 合法並放行。類似地，`1.5` 會由舊算法算成 1、SQL 算成 1.5。

建議改法：資料庫端只聚合 `typeof(reserved_amount) = 'integer'` 的列；同時檢查是否存在租戶相符但型別不是 `integer` 的計入列，存在就走明確的毀損停機路徑或舊算法，不能讓 SQLite 自動轉型。新增文字、REAL、BLOB、NULL 等直接寫入資料庫的對照測試，驗證不會因快路徑而多放行。

### F3 「不跟隨符號連結」沒有涵蓋父目錄，現有安全讀檔無法兌現設計承諾
severity: major
blocking: 是
引句:「每次呼叫照舊做安全讀檔:開目錄與檔案、檢查擁有者與權限、不跟隨符號連結、大小上限、讀完整份內容。」
現有安全讀檔以 `os.open(path.parent, O_DIRECTORY)` 開父目錄，沒有使用 `O_NOFOLLOW`；只有最後的檔名使用 `O_NOFOLLOW`。因此父目錄是符號連結時仍會跟隨，之後的擁有者與權限檢查只檢查連結目標。現有測試也只覆蓋設定檔本身是符號連結，沒有覆蓋任一路徑目錄元件。file: `src/rtb/executor/capability_signer.py:63`；file: `src/rtb/executor/capability_signer.py:71`；file: `tests/executor/test_capability_signer.py:138`

具體例：設定路徑為 `/app/current/tenants.json`，其中 `current` 是指向另一個安全目錄的符號連結，檔案內容與快取相同 → 依設計「不跟隨符號連結」應拒簽 → 照現有安全讀檔實作會跟隨 `current`、檢查目標目錄及檔案後正常簽發；[S685] 的檔案符號連結案例仍會通過，抓不到這個缺口。

建議改法：先明確裁定安全邊界。若所有路徑元件都不得是符號連結，應逐層以目錄描述符和 `O_NOFOLLOW | O_DIRECTORY` 開啟，再相對開下一層，並在快取命中與未命中各測一次父目錄及中間目錄符號連結；若只禁止最後一個檔案元件，則必須縮窄設計承諾與 [S685]，不能宣稱整條讀檔路徑都不跟隨符號連結。
