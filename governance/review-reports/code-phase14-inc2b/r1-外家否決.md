## 發現 1：AI 入口會替暫停或資料異常的廣告建立加預算提案
severity: blocker
blocking: 是

引句:「再用基本資料判九條的第 1/2 條(暫停、1 小時資料異常),命中就結案、不需要追加查詢([S1401]);」

新規則在 `src/rtb/analyzer/policy.py:283` 已把暫停與異常判為基本資料可結案，但 AI 前置過濾在 `src/rtb/analyzer/ai_judge.py:93` 仍只檢查資料、狀態與配速，沒有檢查 `facts.settled_by_base`。這兩類廣告只要配速偏低，就會進模型；模型回合法 `propose` 時，`src/rtb/analyzer/ai_judge.py:145` 直接建立提案，`src/rtb/analyzer/flow.py:472` 直接提交為 `PROPOSED`。這是第 1／2 條當場可否決的誤提案，與留到增量 3 的四查詢否決無關。

最小重現使用現有測試的假模型，沒有呼叫真模型：

```sh
PYTHONPATH=src:. .venv/bin/python -B -c 'from tests.analyzer.test_ai_judge import Model, reply, CITE_BASE, base_evidence, run

for label, evidence in (("paused", base_evidence(status="paused")), ("anomaly", base_evidence(clicks=600))):

    outcome, _ = run(model, evidence)
    print(label, steps(evidence, NOW).rule.reason.value, len(model.sent), isinstance(outcome.result, ProposalDecision))'
```

```text

```
