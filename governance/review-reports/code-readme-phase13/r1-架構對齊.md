## 發現 2:流程圖把「程式初篩沒過」畫成交給程式規則判斷，跟 flow.py 不符

## 發現 4:SVG 每次重畫輸出都不同，而且圖例、註記沒跟 GIF 共用同一份資料
severity: minor
blocking: 否

引句:「for kind in {row[3] for row in EDGES}:」

箭頭標記是對一個集合逐項 `insert(3, …)` 插進去的。集合的順序會隨 PYTHONHASHSEED 變。我在 /tmp 複本用種子 1 到 5 重跑，五次的 `<marker>` 順序都不一樣。已提交的 SVG 跟重畫結果逐位元比對不同，排序後比對才相同。之後每次重畫都會產生沒有實質內容的 diff。GIF 重畫則跟已提交的逐位元組相同。

另外兩點：
- **圖例不同源**：SVG 圖例是一整段白字「程式　　AI　　人工／回頭線…」，沒有像 GIF 那樣各標自己的顏色，當不了顏色對照。三段註記文字在 `_frame` 和 `_write_svg` 各寫了一份，座標也不同（y 312/313 對上 315），不符「單一資料來源」。
- **箭頭過大**：`markerWidth="8"` 搭配線寬 3，箭頭實際約 24px，是舊版的兩倍以上；用 qlmanage 算圖可以看到箭頭壓到節點框。

建議：改成 `sorted({…})`；圖例和註記抽成常數，兩邊共用。

架構對齊的其他部分沒問題：仍是同一支腳本、同一組 NODES 和 EDGES 同時畫 GIF 與 SVG；只用 Pillow 和標準庫，沒動 requirements 或 pyproject；`ruff check` 通過。
