## 新增開場粗體宣言,脫離既有「條列＋粗體結論句」結構

severity: major
blocking: 否
引句:「這個 Demo 不假設 AI 應該擁有決策權；每一項決策權都必須由評估與可驗證的證據取得。」

現有 README 的粗體用法只有一種:出現在「## 怎麼運作」「## 做了哪些把關」條列項目的行首,當作該行的結論句,後面緊接不加粗的說明文字(例:「**要不要加預算，由程式規則決定。**規則依序看九件事…」)。本次新增這句粗體,是獨立成段落、放在 H1 標題和原本的介紹段落之間,不在任何條列項目裡,句子本身也用分號串了兩個子句,後面沒有接不加粗的解釋文字。這是把粗體從「條列項目的結論句」變成「獨立宣言段落」,等於引入第二種粗體用法。建議把這句話的內容併入既有介紹段落,或改寫成「## 怎麼運作」底下的一個條列項目,讓粗體只有一種用法。
